# スタジオスケジュール集約プログラム

起動するたびに各スタジオの最新スケジュールを取得し、ブラウザで一覧表示するツールです。

## 対象スタジオ

**ゴールドジム**
- 原宿東京 / 原宿Annex / 表参道 / 渋谷 / 四ツ谷 / 代々木上原 / 南青山 / サウス東京 / 溝の口

**チャコットスタジオ**
- 代官山

## 機能

- 起動時に全店舗の最新スケジュールを自動取得
- インストラクター名・プログラム名で検索
- 曜日・店舗・プログラム種別でフィルター
- リスト表示 / カード表示の切り替え

## 必要環境

- Python 3.8 以上
- インターネット接続

## インストール・実行

```bash
# 初回のみ：依存パッケージとPlaywrightブラウザをインストール
pip install playwright pdfplumber beautifulsoup4
python -m playwright install chromium

# 実行（毎回これだけでOK）
python schedule_aggregator.py
```

実行すると `schedule.html` が生成され、ブラウザで自動的に開きます。

## 注意事項

- スケジュールPDFが取得できない店舗はエラー表示されます
- サイトの構造変更によりデータが取得できない場合があります
